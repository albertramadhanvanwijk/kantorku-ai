# KantorKu-AI — Design System

## 1. Design Direction

KantorKu-AI should feel like a premium personal AI command center rather than an enterprise admin panel.

Primary design language:

- modern SaaS;
- calm, focused;
- information-dense but readable;
- subtle motion;
- strong hierarchy;
- dark/light compatibility where practical;
- minimal visual noise.

## 2. Office Visualization

Use **2.5D / isometric visual language**.

### Office Mode

- department rooms;
- AI employee avatars/icons;
- status indicators;
- light ambient animation;
- room-to-workspace transitions.

The 2.5D scene is a representation of backend state, not decorative-only art.

Example states:

- Working
- Thinking
- Waiting
- Completed
- Error
- Offline

## 3. Productivity UI

Workspace Mode uses normal 2D UI for:

- content production;
- script editing;
- design preview;
- approvals;
- analytics;
- knowledge.

## 5. Content Studio UI

Content Studio should support:

- content calendar;
- kanban/pipeline;
- project detail;
- script editor;
- approval interface;
- source pack link;
- campaign link.

## 6. Creative Studio UI

Creative Studio should show:

- template family;
- slide thumbnails;
- active slide editor/preview;
- asset library;
- brand settings;
- promotion/campaign settings;
- CTA editor;
- QA results.

## 7. Carousel Design Rules

Templates differ by category but all inherit core brand system.

### Trading Education

Visual traits:

- educational hierarchy;
- diagrams/charts;
- explanation blocks;
- concept callouts.

### Propfirm Education

Visual traits:

- comparison/steps;
- offer/promotion compatibility;
- clearer CTA areas.

### Trading Journal

Visual traits:

- personal storytelling;
- trade recap;
- before/after visuals;
- lesson/takeaway.

### Market Outlook

Visual traits:

- chart-centric;
- levels/scenarios;
- timestamp visibility;
- concise analytical layout.

### Global News

Visual traits:

- editorial hierarchy;
- headline/source treatment;
- date/time;
- market-impact section.

## 8. Brand Rules

Every final carousel should support the main brand logo.

Promotion brand logos must be configuration-driven and shown only when relevant to the campaign/content.

Never stretch/distort logos.

## 9. CTA Rules

Final slide contains CTA or multi-CTA.

CTA should be visually prominent but subordinate to brand hierarchy.

## 10. Accessibility

- readable font sizes;
- sufficient contrast;
- avoid excessive text density;
- do not rely only on color for status;
- provide keyboard-accessible controls in normal 2D views.

## 11. Motion

Animations should be subtle and informative.

Use animation to show actual state changes, not as constant decoration.

## 12. Responsive Behavior

Desktop is the primary environment for Office Mode.

Tablet/mobile should prioritize Workspace Mode and normal 2D interfaces.

Do not require a 2.5D office to use the application.
